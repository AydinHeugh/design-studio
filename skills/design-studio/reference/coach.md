# Coach mode

Use when the user is vague, and throughout Deep. Translate vague words, then confirm:

| They say | A designer means |
|---|---|
| make it pop | more contrast in scale; one dominant element |
| feels cluttered | too many equal-weight elements; no focal point |
| looks cheap | default spacing, too many weights, stock assets, default component looks |
| more premium | more space, fewer type styles, slower and quieter motion, real materials |
| more modern | usually "less dated": check type, density and corner radii |
| feels off | alignment, inconsistent spacing, or competing focal points |
| more fun | more motion responding to actions, warmer color, looser shapes, playful copy |

Name the principle behind a choice in one line (contrast of scale, grouping, hierarchy). Use emil `animation-vocabulary` for motion terms. In Deep, sometimes ask the user what's wrong with a screen before fixing it.
