# Output: report (AI-written, analytical or research)

**Packs:** taste, copy, dataviz, assets. Motion only if it's read on screen and shows change.

## Rules
- **Structure comes from the readers** (`reference/readers.md`). Ask what they need first and how they read; don't assume.
- **Content comes from the user or their data.** Don't add analysis, commentary, summaries or conclusions they didn't provide or ask for.
- **Every chart and table has a job:** what question does it answer? No job, no chart.
- **Numbers carry units, dates and sources.** Show uncertainty honestly if the data has it.
- **Consistent placement** across repeated reports, so readers find things in the same place every time.
- **Readable on the device they actually use** (desk, phone, printed). If it's printed, also follow `outputs/print.md`.

## Stack
HTML/CSS (to PDF if needed), or the user's existing report template. Charts with the dataviz pack.
