# Job: reskin (new UI, same UX)

**Keeps (frozen):** flows, navigation, screen structure, content, and exactly what every control does, in the same place.
**Changes:** the visual layer only: type, color, spacing, how components look, icons, motion.

**Confirm with the user:** "I'll keep how everything works and where it is. I'll change only how it looks." List the screens in scope. Ask if anything should move between the lists.

**Directions differ in:** identity (look and feel) on the existing structure.

**Watch for:** moving or renaming a control, or adding or removing a step. That's a UX change; suggest it separately, never make it. Keep the same states (loading, empty, error) the app already has.
