# Job: polish

**Keeps (frozen):** identity, layout, flows, content.
**Changes:** details only: spacing, alignment, type sizes and weights, component states, contrast, motion timing, clarity of wording the user approves.

**Confirm with the user:** list the screens in scope and confirm nothing structural changes.

**No directions.** Instead of step 6, show a numbered list of proposed fixes, each with before, after and why. The user approves which to apply (all, some, none). Then build only the approved fixes.

**Watch for:** fixes that quietly become a redesign. If a fix needs a layout or identity change, list it separately as a suggestion.
